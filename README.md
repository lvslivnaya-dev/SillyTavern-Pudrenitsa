# Пудреница — для SillyTavern

**[Руководство](docs/РУКОВОДСТВО.md)** · [Изменения](CHANGELOG.md)

Мягкая стеклянная тема с котиками и лапками и новые окна вместо родных шторок SillyTavern. Персоны, персонажи, расширения и лорбуки становятся библиотеками с папками, поиском и обложками, а все настройки таверны собраны в одно окно.

*A cozy pastel glass theme for SillyTavern with cats and paws, plus new windows instead of the stock drawers: a settings hub, preset toggle chips, a chat library on the start screen, and libraries for personas, characters, extensions and lorebooks with folders, search and covers. Five palettes. Russian UI.*

## Что внутри

- **Тема и палитры.** Стекло, пуговки, ушки на попапах и поле ввода, лапки на фоне. Пять палитр: Пудра, Графит и мёд, Ночь и вишня, Кофе с молоком, Салат и роза. Свои палитры: любой цвет пипеткой или кодом, или подбор всех цветов по описанию через подключённую модель. Свои шрифты и цвета для повествования, речи и мыслей.
- **Окно «Пудреница».** Ответ ИИ, соединение, формат ответа, пользователь и фон — вкладками в одном окне вместо пяти шторок.
- **Кнопки пресета.** Любимые тогглы Prompt Manager полоской над чатом, с короткими подписями. Набор свой для каждой пары «пресет + профиль соединения».
- **Библиотека чатов** на стартовом экране вместо приветствия: продолжить, закреплённые, частые, архив, фандомы по тегам.
- **Персоны и персонажи.** Библиотеки с папками, избранным, архивом, поиском и выбором нескольких. Карточку персонажа можно править, не открывая его чат.
- **Расширения.** Включить, выключить, удалить и обновить в одном месте, фильтры «Нужно обновить» и «Отключённые», папки, родные настройки расширения справа.
- **Лорбуки.** Обложки, вложенные папки, глобальное включение тумблером, переименование двойным кликом. Свой редактор записей с автосохранением: вторичные ключи стоят под основными, логика между ними.
- **Мелочи для чата.** Кнопка-лапка вместо «≡» и волшебной палочки, кнопка «скрыть от ИИ сообщения с № по №», котик, который гуляет по полю ввода, пока ИИ печатает ответ.

## Установка

Нужна **SillyTavern 1.19.0** или новее.

1. **Extensions** → **Install extension**.
2. Вставьте адрес репозитория:
   `https://github.com/lvslivnaya-dev/SillyTavern-Pudrenitsa`
3. Обновите страницу.

**Выключите расширения, которые Пудреница заменяет** (Extensions → Manage extensions): MistraelSL Persona Panel, MistraelSL Extension Manager, MistraelSL Character Chat Pills и My lorebook manager. Если они включены, Пудреница предупредит. Их папки, избранное, закрепления и обложки Пудреница один раз переносит к себе сама.

Свой CSS в User Settings → Custom CSS может перекрасить тему, Пудреница об этом тоже предупредит.

## Как это устроено

- Родные панели таверны Пудреница не переписывает: она переносит их в свои окна, а при выключении возвращает на место. Всё, что меняет тема, живёт под меткой `body.pud-on`.
- Чужие расширения, которые берут цвета из переменных темы SillyTavern, перекрашиваются вместе с палитрой.
- В окне «Пудреница» есть кнопка «Выключить до перезагрузки»: снимает тему и окна сразу, без F5.

## Данные

- Настройки, папки, обложки и вид окон хранятся в настройках расширений SillyTavern (`extensionSettings.pudrenitsa`).
- Обложки лорбуков загружаются в `user/images/pudrenitsa-covers`.
- Пудреница ничего не отправляет наружу и не делает своих запросов к моделям.

## Шрифты

Nunito, Lora, Comfortaa, Caveat, Lobster и Marck Script под SIL Open Font License 1.1. Лицензии лежат в [assets/fonts/licenses](assets/fonts/licenses).

## Разработка

Нужен Node.js 20 или новее. Само расширение без зависимостей и без сборки: это браузерные ES-модули. Для тестов используется jsdom (только как dev-зависимость).

```bash
npm ci
npm test
```

Ручная проверка по шагам — в [docs/MANUAL-TESTS.md](docs/MANUAL-TESTS.md).
