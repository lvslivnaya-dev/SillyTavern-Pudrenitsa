# Изменения

## 0.1.0 — 2026-11-06

Первый выпуск.

- **Тема.** Стекло, пуговки, ушки на попапах и поле ввода, лапки на фоне, свои чекбоксы и ползунки. Чужие расширения, которые берут цвета из темы SillyTavern, перекрашиваются вместе с ней. Свободные шрифты с кириллицей (SIL OFL 1.1).
- **Палитры.** Пудра, Графит и мёд, Ночь и вишня, Кофе с молоком, Салат и роза. Переключаются на лету во вкладке «Палитра».
- **Чат.** Портреты с ушками, разные шрифты и цвета для повествования, речи и мыслей, размышления в пилюле, [Timeskip …] разделителем, кнопка перегенерации.
- **Окно «Пудреница».** Ответ ИИ, Соединение, Формат ответа, Пользователь и Фон вкладками, ссылки, «Выключить до перезагрузки». Общие окна: таскаются, меняют размер, сворачиваются в док, закрываются только крестиком, помнят место.
- **Кнопки пресета.** Тогглы Prompt Manager полоской над чатом, набор на пару «пресет + профиль соединения».
- **Библиотека чатов** на стартовом экране, окно «Все чаты», кнопка «закрыть чат».
- **Персоны.** Библиотека с папками, избранным, архивом, поиском, импортом, экспортом и выбором нескольких. Описание в своём окне с автосохранением, привязки, несколько персон на персонажа.
- **Персонажи.** Такая же библиотека, правка карточки без открытия чата, расширенное описание, экспорт, клон, «сделать персоной».
- **Расширения.** Включить, выключить, удалить, обновить, папки, фильтры, родные настройки расширения в окне, Extras API под ключиком.
- **Лорбуки.** Библиотека с обложками, вложенными папками, глобальным включением, переименованием двойным кликом и перевязкой ссылок. Свой редактор записей с автосохранением, вторичными ключами под основными и тонкими настройками. Общие настройки активации в библиотеке.
- **Поле ввода.** Одна кнопка-лапка вместо «≡» и волшебной палочки, кнопка «скрыть от ИИ сообщения с № по №», котик при стриминге.
- **Переезд.** Один раз переносятся данные MistraelSL Character Chat Pills, MistraelSL Persona Panel и My lorebook manager. О включённых заменяемых расширениях и о своём Custom CSS Пудреница предупреждает при запуске.
